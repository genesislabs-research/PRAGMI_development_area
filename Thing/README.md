# Timmyv4
Genesis Labs Research

A de novo spiking neural network with a recurrent self-loop identity core and
a staged language acquisition system. Every neuron in every population is a
state-space model leaky integrate-and-fire unit. There are no dense softmax
layers, no attention heads, and no transformer blocks anywhere in the
load-bearing architecture.

---

## What this is

Timmyv4 is an attempt to build the world's first artificial semi-sapient
system from scratch using biologically grounded components. The system has a
continuously running recurrent loop between a posterior hub and an anterior hub
(the I-am core), a manifold of acquired concept representations (the lemma
stratum), and a six-population language organ that develops through a staged
curriculum analogous to first-language acquisition in children.

The system models a point of view. It represents its own ignorance at boot
(doubt >= 0.5 before any concept is confirmed), tracks autobiographical
episodes via theta-gated episodic writes, and acquires new concepts only when
dopamine, acetylcholine, and local membrane depolarization coincide. It does
not have a personality hard-coded into its weights. Whatever it becomes, it
becomes through learning.

## Documentation standard

Every class in every PART file carries a single comment `# RM###` before its
definition. The RM number is the entry number in the "The code classes
explained" section below. All biological grounding, citations, and parameter
derivations live in that section, not in the code. Engineering labels (NOT
biological, training artifact) remain inline in the code on the specific
parameters they label.

## The code classes explained

The entries below are ordered by RM number. Each entry names the class, its
anatomical referent, what that structure does in the actual brain, and the
papers that ground the implementation decisions.

---

### RM101: SubstrateState

Dataclass carrying the four state variables of one SSM-LIF population: the
hidden state h of the state-space model (shape batch × neurons × n_dim), the
membrane potential v (batch × neurons), the adaptive threshold θ (batch ×
neurons), and the last spike output (batch × neurons).

All four tensors are detached before being returned across a tick boundary.
This prevents gradients from flowing through the recurrent dynamics during
R-STDP updates, which are explicitly in-place under torch.no_grad. Surrogate
gradients for within-tick backpropagation are preserved separately via the
forward/backward hooks on spike_fn.

---

### RM102: HeavisideWithSurrogate and spike_fn

The Heaviside step function with a surrogate gradient for backpropagation
through spike events. In the forward pass, a neuron spikes when its membrane
potential equals or exceeds its threshold. In the backward pass, the true
zero-almost-everywhere gradient is replaced with the derivative of a fast
sigmoid: `alpha / (1 + alpha |v - θ|)^2`.

The surrogate gradient is a training artifact, not a biological quantity. The
actual brain uses spike-timing-dependent plasticity, not backpropagation
through spiking events. The surrogate is labeled NOT biological wherever the
alpha parameter appears in code.

Neftci, E.O., Mostafa, H., and Zenke, F. (2019). "Surrogate Gradient
Learning in Spiking Neural Networks." IEEE Signal Processing Magazine, 36(6),
51-63. DOI: 10.1109/MSP.2019.2931595

---

### RM103: SpikeMixer

A one-layer linear projection followed by GELU activation that converts a
spike vector into a smooth continuous representation. Used at the B44-to-B45
boundary in BrocasModule and at selected other population interfaces where a
rate-coded summary of spike activity is needed.

The GELU activation approximates the nonlinear gain of the thalamic relay
populations that mediate between timing-coded and rate-coded cortical regions.
This is a computational approximation; the exact thalamic relay mechanism is
not modeled.

### RM104: SSMLIFSubstrate

The core computational unit of the entire architecture. Every neuron in every
population in every PART file is an instance of this class. It combines a
state-space model (SSM) for temporal memory with a leaky integrate-and-fire
(LIF) neuron for spiking output, plus a liquid-time-constant (LTC) gate that
makes the effective membrane time constant input-dependent.

The SSM component follows the HiPPO-LegS initialization, which initializes
the state matrix A to project incoming signals onto the Legendre polynomial
basis. This allows the hidden state h to maintain a compressed history of the
recent input stream. A is frozen after initialization; it is a developmental
prior, not a trainable parameter.

The update equations are:

```
h[t] = A h[t-1] + B x[t]                    (SSM state update)
drive[t] = C · h[t]                          (output projection)
gate[t] = σ(W_x x[t] + W_v v[t-1] + b)     (LTC gate)
v[t] = (1 - gate) v[t-1] + gate (drive + v_rest)   (membrane update)
s[t] = H(v[t] - θ[t])                       (spike)
v[t] = v[t] - s[t] θ[t]                     (subtractive reset)
θ[t] = ρ_θ θ[t-1] + Δ_θ s[t]              (adaptive threshold)
```

HiPPO initialization:
Gu, A., Dao, T., Ermon, S., Rudra, A., and Ré, C. (2020). "HiPPO: Recurrent
Memory with Optimal Polynomial Projections." Advances in Neural Information
Processing Systems 33. DOI: 10.48550/arXiv.2008.07669

Liquid time-constant networks:
Hasani, R., Lechner, M., Amini, A., Rus, D., and Grosse-Wentrup, M. (2021).
"Liquid Time-constant Networks." Proceedings of the AAAI Conference on
Artificial Intelligence, 35(9), 7657-7666.
DOI: 10.1609/aaai.v35i9.16936

Adaptive threshold (spike-frequency adaptation):

Neurophysiology, 94(5), 3637-3642. DOI: 10.1152/jn.00686.2005

### RM105: hippo_legs_init and discretize_zoh

Two utility functions. hippo_legs_init returns the continuous-time A and B
matrices for the HiPPO-LegS parameterization. discretize_zoh converts them to
discrete-time using zero-order hold (matrix exponential for A, Cayley
approximation for B).

The HiPPO-LegS A matrix satisfies `A_{nk} = -(2n+1)^{1/2}(2k+1)^{1/2}` for
n > k, `A_{nn} = -(n+1)`, zero elsewhere. This produces a state that maintains
optimal projections of the input history onto shifted Legendre polynomials.

Gu, A., Dao, T., Ermon, S., Rudra, A., and Ré, C. (2020). "HiPPO: Recurrent
Memory with Optimal Polynomial Projections." NeurIPS 33.
DOI: 10.48550/arXiv.2008.07669

### RM202: OperatingCondition

Enum encoding the four operating states of the I-am core: COLD (no memory,
no omega), WARM (omega stable, no novel content), ENCODING (novel content
being written to episodic memory), and RETRIEVING (past content being read
back). The operating condition is determined each tick from novelty and theta
phase, and governs whether the write gate fires.

### RM205: RSTDPRule

Implements the three-factor learning rule. A pre-synaptic eligibility trace
decays with time constant tau_pre. A post-synaptic eligibility trace decays
with tau_post. Weight updates fire only when a neuromodulatory signal (omega's
dopamine channel) exceeds the burst threshold. LTP magnitude: `eta * DA *
pre_trace * post_spikes`. LTD magnitude: `eta * DA * pre_spikes * post_trace *
depression_ratio`.

The three-factor formulation implements Hebbian plasticity gated by
neuromodulatory coincidence. The dopamine signal represents prediction error
in the basal ganglia-cortical loop; the cholinergic signal represents
attention and novelty gating.

Schultz, W., Dayan, P., and Montague, P.R. (1997). "A Neural Substrate of
Prediction and Reward." Science, 275(5306), 1593-1599.
DOI: 10.1126/science.275.5306.1593

Frémaux, N. and Gerstner, W. (2016). "Neuromodulated Spike-Timing-Dependent
Plasticity, and Theory of Three-Factor Learning Rules." Frontiers in Neural
Circuits, 9. DOI: 10.3389/fncir.2015.00085

### RM206: EpisodeRecord

Dataclass representing one entry in the autobiographical episodic memory.
Carries the coordinate vector, the omega snapshot at encoding time, the tick
number, novelty score, and tau_proj flag. Records with tau_proj=1 are refused
by the write gate; only tau_proj=0 content enters the causal record. This
implements the architectural commitment that projected (imagined) content does
not contaminate the autobiographical trace.

---

### RM207: WriteGate

Enforces theta-phase and tau_proj constraints on episodic writing. The gate
fires only on the rising phase of the theta oscillation
(`sin(2π f_theta t) > 0`) and only for tau_proj=0 records. Theta-phase gating
of episodic encoding matches the hippocampal-cortical transfer mechanism
documented in Hasselmo (2005).

Hasselmo, M.E. (2005). "What is the function of hippocampal theta rhythm?
Linking behavioral data to phasic properties of field potential and unit
recording data." Hippocampus, 15(7), 936-949. DOI: 10.1002/hipo.20116

---

### RM208: RetrievalDraw

Samples from the episodic store using omega-weighted cosine similarity.
Past episodes whose omega patterns are cosine-similar to the current omega
vector are weighted exponentially and a record is drawn proportionally. This
implements content-addressable retrieval analogous to the attractor dynamics
of hippocampal CA3.

Hopfield, J.J. (1982). "Neural networks and physical systems with emergent
collective computational abilities." Proceedings of the National Academy of
Sciences, 79(8), 2554-2558. DOI: 10.1073/pnas.79.8.2554

### RM210: SynapticReentryRegister

Maintains a discretized register of reentry states for the I-am core's
slow-loop feedback pathway. The register ladders across 20 quantized states
(epsilon=0.05) and is updated by the pcc-averaged reentry signal at each
theta tick. State transitions implement the low-dimensional summary that
persists across the ignition latency gap.

The register models the slow timescale of synaptic consolidation that sustains
the self-referential signal across the 160 ms ignition delay documented by
Lou et al. (2017).

Lou, H.C., Changeux, J.-P., and Rosenstand, A. (2017). "Towards a cognitive
neuroscience of self-awareness." Neuroscience and Biobehavioral Reviews, 83,
765-773. DOI: 10.1016/j.neubiorev.2016.04.004

### RM212: IamCore

The I-am core. A continuously-running recurrent loop between four SSM-LIF
populations modeling the posterior-anterior axis of the brain's default mode
network. The loop ignites simultaneously at 160 ms latency per Lou et al.
(2017). The omega neuromodulatory vector and r_reentry signal are broadcast
to the language organ at each tick.

The four populations and their anatomical referents:

| Population | Anatomical region | Role |
|---|---|---|
| proto_self | Brainstem / PAG | Interoceptive state integration |
| pcc | Posterior cingulate cortex | Broadcast driver, self-referential hub |
| mpfc | Medial prefrontal cortex | Inhibitory valve, valence evaluation |
| ipl | Inferior parietal lobule | Lateral integrator, agency signals |

The inter-region connectivity pattern is initialized from the DCM Model 27
of Davey et al. (2016), which isolates the self-referential sub-network of
the default mode network. The mpfc-to-pcc projection is inhibitory (negative
endogenous and modulatory weights) consistent with the anterior inhibitory
valve function documented by Northoff and Bermpohl (2004).

The ignition latency of 160 ms implements the simultaneous anterior-posterior
ignition documented by electrophysiological and fMRI work on conscious access.

Davey, C.G., Pujol, J., and Harrison, B.J. (2016). "Mapping the self in the
brain's default mode network." NeuroImage, 132, 390-397.
DOI: 10.1016/j.neuroimage.2016.02.022

Lou, H.C., Changeux, J.-P., and Rosenstand, A. (2017). "Towards a cognitive
neuroscience of self-awareness." Neuroscience and Biobehavioral Reviews, 83,
765-773. DOI: 10.1016/j.neubiorev.2016.04.004

Northoff, G. and Bermpohl, F. (2004). "Cortical midline structures and the
self." Trends in Cognitive Sciences, 8(3), 102-107.

### RM301: LemmaStatus

IntEnum with four values: UNALLOCATED=0, SCAFFOLD=1, PROVISIONAL=2,
CONFIRMED=3. Every row of the lemma stratum carries exactly one of these
statuses. SCAFFOLD rows are written at boot and locked thereafter.
PROVISIONAL rows are candidates awaiting sleep consolidation. CONFIRMED rows
are fully acquired concepts.

### RM304: LemmaStratum

The central representation hub of the language organ. Models the mid-temporal
cortex sector of the conceptual semantic system. The lemma stratum maintains a
4106-dimensional manifold of concept representations (10 scaffold anchors plus
4096 reservoir), organized so that the geometric relationships between
concepts reflect their semantic relationships.

The manifold has five committed axes. Each axis encodes a fundamental
epistemic or semantic distinction:

| Axis | Dimension | Poles | Distance |
|---|---|---|---|
| 0 | Self/Other | SELF +0.50, OTHER −0.50 | 1.0 |
| 1 | Familiarity | FAMILIAR_OTHER +0.20, UNFAMILIAR_OTHER −0.20 | 0.4 |
| 2 | Epistemic state | KNOWING +0.50, NOT_KNOWING −0.50 | 1.0 |
| 3 | Temporal reference | FUTURE +0.50, PAST_PRESENT −0.50 | 1.0 |
| 4 | Logical | AND +0.35, NOT −0.35 | 0.7 |

The four operating rhythms:

R1 (1 ms): SSM-LIF substrate forward. Spike propagation via W_LL (recurrent).

R2 (short-term): R-STDP under three-factor gate. Cholinergic pause (omega[2]
< 0.3) plus dopamine burst (omega[0] > 0.5) plus local membrane
depolarization above 0.4 of threshold must all coincide. This implements the
neuromodulatory coincidence requirement for synaptic consolidation.

R3 (250 ms): Spring dynamics over the coordinate manifold. Per-lemma mass
scales with confirmation count (heavier confirmed lemmas resist displacement).
K-matrix is the row-normalized random-walk Laplacian over the
acquired-lemma connectivity graph (force = (D^-1 W - I) x), with spring
constants k_ij = alpha * w_ij^1.5 (Hebbian weight to the 1.5 power) before
row normalization. Each lemma is pulled toward the weighted mean position of
its neighbors irrespective of degree, producing stable manifold equilibria
where semantic neighbors cluster without high-degree hub lemmas becoming
rigidly anchored. Scaffold rows have velocity and acceleration zeroed after
each step.

R4 (sleep): Offline consolidation. 500 Poisson-noise ticks. PROVISIONAL rows
with incident W_LL weight sum > 1.0 are promoted to CONFIRMED; rows with
weight sum < 0.05 are reclaimed to UNALLOCATED.

The cascade output c_cas = a_l @ W_CtoL.t() feeds ONLY into
IamCore.forward(coords=c_cas). It does not wire to the autobiographical
readout pathway. This separation preserves the distinction between present
linguistic content and autobiographical memory.

The LC flipflop models the locus coeruleus norepinephrine oscillation with a
70-second period. During high-NE phase, distant lemmas (low cosine similarity
with currently active lemma) are suppressed, implementing the
exploration-exploitation dynamic of the LC-NE system. The implementation
follows Aston-Jones and Cohen (2005) gain-modulation account of LC function.
This is the v4 simplification of the architectural commitment to Davy (2022)
cross-modular reciprocal inhibition with autonomous biphasic oscillation; the
Davy refactor is a v5 deliverable.

Rolls, E.T. (2012). "Neocortical bases of working memory." The Neuroscientist,
18(3), 215-231. DOI: {To be added later.}

Chung, S., Lee, D.D., and Sompolinsky, H. (2018). "Classification and
Geometry of General Perceptual Manifolds." Physical Review X, 8, 031003.
DOI: 10.1103/PhysRevX.8.031003

### RM305: PhonologicalCodeStore

Models the phonological lexicon centered on Wernicke's area (posterior
superior temporal gyrus). Maintains a 4106-row parallel representation to the
lemma stratum, one phonological code embedding per acquired lemma. Production
converts a lemma index to a 64-dimensional phonological code vector phi via
W_LtoP. Comprehension runs the reverse via W_LtoP.t(), converting phoneme
evidence into lemma activation after a 160 ms perception delay.

The segment decoder is 100% SSM-LIF (64 neurons, n_hidden=16, alpha=0.8
timing-coded). It produces phoneme sequences autoregressively: 25 substrate
ticks per segment, capped at 20 segments. No LSTM, no transformer.

W_LtoP is a single nn.Parameter of shape (4106, 64). Production uses it
directly; perception uses its transpose. This is the tied-weight pattern.

Wernicke's aphasia ablation zeroes W_LtoP. Production then emits phoneme
index 0 always; perception returns zero lemma activation. This matches the
clinical presentation of Wernicke's aphasia (fluent but meaningless speech,
poor comprehension).

Wernicke, C. (1874). "Der aphasische Symptomenkomplex." Cohn und Weigert.
{DOI not applicable - historical monograph.}

Hickok, G. and Poeppel, D. (2007). "The cortical organization of speech
processing." Nature Reviews Neuroscience, 8(5), 393-402.
DOI: 10.1038/nrn2113

### RM306: BrocasModule

Models Broca's area (BA44 and BA45) and its role in phonological assembly and
syntactic planning. Two SSM-LIF populations with different computational roles:

B44 (1024 neurons, alpha=0.8 timing-coded): pars opercularis. Receives
phoneme inputs via W_seg_to_B44, implements the cluster operator that
assembles phonemes into syllable-level units (sigma). Timing-coded because
syllabic binding requires precise spike order to maintain sequential
phoneme structure.

B45 (1024 neurons, alpha=2.0 rate-coded): pars triangularis. Receives B44
SpikeMixer output, implements higher-order syntactic and morphological
representations. Rate-coded because syntactic categories are maintained across
the duration of a phrase, not locked to precise spike times.

The receptor density priors are from Amunts et al. (1999) cytoarchitectonic
analysis of BA44 and BA45:

```
B44: GABA-A scaling 1.3, DA 1.0, 5-HT 1.0
B45: DA scaling 1.4, 5-HT 1.3, GABA-A 1.0
```

These scaling factors are stored as non-trainable buffers and can be used to
modulate receptor-specific drug effects in disorder modeling.

The resyllabification mechanism implements the phonological re-encoding that
occurs when a longer form of a word is encountered. When a new vowel arrives
after a completed sigma and the previous coda contains a multi-consonant
cluster, the coda-final consonant transfers to the onset of the new sigma
(one rollback per arriving segment maximum).

Broca, P. (1861). "Remarques sur le siège de la faculté du langage articulé."
Bulletins de la Société Anatomique de Paris, 6, 330-357.
{DOI not applicable - historical.}

Amunts, K., Schleicher, A., Burgel, U., Mohlberg, H., Uylings, H.B.M., and
Zilles, K. (1999). "Broca's region revisited: Cytoarchitecture and intersubject
variability." Journal of Comparative Neurology, 412(2), 319-341.
DOI: 10.1002/(SICI)1096-9861(19990920)412:2<319::AID-CNE10>3.0.CO;2-7

Friederici, A.D. (2011). "The brain basis of language processing: from

### RM307: ArcuateTransport

Models the arcuate fasciculus, the white-matter tract connecting Wernicke's
area (posterior temporal) to Broca's area (inferior frontal). NOT a neural
population. A frozen near-identity linear projection plus a delay buffer.

The projection matrix W_arc = I + 0.01 N(0,1) represents the topographic
organization of the arcuate: axons transmit information with approximately
preserved spatial structure, plus a small amount of mixing from fiber crossing.
W_arc is frozen at construction (requires_grad=False) because white-matter
axonal architecture does not change on the timescale of single-session learning.

The delay buffer length is ceil(7.5 ms / dt_ms) = 8 ticks at dt_ms=1.0.
The 7.5 ms is the midpoint of the 5-10 ms DTI-derived conduction velocity
range for the arcuate.

Ablation zeroes W_arc, producing the conduction aphasia phenotype:
phonological output from P but no syllable assembly in B44. This matches
the clinical presentation of conduction aphasia (relatively intact comprehension
and production separately, impaired repetition).

Catani, M., Jones, D.K., and ffytche, D.H. (2005). "Perisylvian language
networks of the human brain." Annals of Neurology, 57(1), 8-16.
DOI: 10.1002/ana.20319

### RM308: ProductionLoop

Thin orchestrator. No own substrate. Owns references to LemmaStratum,
PhonologicalCodeStore, ArcuateTransport, and BrocasModule. A single call to
produce(lemma_idx) runs the full production cycle: retrieve phonological code
from P, autoregressively decode to phoneme sequence, route each phoneme
through the arcuate delay, run the cluster operator in B44/B45, and return
the assembled syllables (sigmas) with rollback count.

The timing budget at dt_ms=1.0:

| Event | Ticks from cascade onset |
|---|---|
| Lemma selection | 175-250 |
| Phonological code retrieved | 250-400 |
| First segment emitted | ~330 |
| First segment in B44 (after arcuate) | ~338 |
| Phonological word complete | ~600 |

### RM309: OrthographyModule

Models the visual word form area (VWFA, left occipitotemporal cortex) and its
dual-route connections to the phonological and lexical systems. Population O
contains 416 SSM-LIF neurons: 26 letters × 16 positions. The position encoding
is positional (which row activates), not a separate embedding layer.

Dual-route architecture per the Dual Route Cascaded model:

Direct lexical route: O → W_OtoL → L. Familiar words activate their lemma
directly within 200 substrate ticks. W_OtoL is a single nn.Parameter (416 ×
4106) accessed directly (forward) and via .t() (reverse for writing/spelling).

Indirect sublexical route: O → W_OtoB44 → B44 → reverse cluster operator
→ phoneme sequence → W_LtoP.t() → L. Total latency 300-400 ticks. Active for

- ablate_lexical_route=True: surface dyslexia. Irregular words regularized.
- ablate_sublexical_route=True: phonological dyslexia. Pseudoword reading fails.

### RM310: CascadeComposer

Models the frontoparietal compositional system centered on inferior frontal
and superior temporal regions (Wernicke-Broca axis plus supramarginal gyrus).
Population X (2048 neurons, alpha=2.0 rate-coded) maintains parallel parse
hypotheses and generates hierarchical predictions about upcoming linguistic
input.

Hierarchical forecasting at two depths per Caucheteux et al. (2023):
- depth=5 (syntactic): temporal cortex level
- depth=8 (semantic): frontoparietal level

At each tick, X is rolled forward in zero-input generative mode for 5 and 8
ticks to produce production and comprehension forecasts respectively. Deeper
rollouts produce higher-entropy predictions because more diverse firing
patterns unfold over a longer horizon.

Parallel hypotheses: n_hypotheses=4 parse candidates maintained via
parse_separator (Linear(2048, 4), softmax). Posterior over hypotheses updated
multiplicatively per Narayanan and Jurafsky (2004) Equation 55:
`P(h|evidence) ∝ P(h) * P(evidence|h)`.

Attention-flip detection fires when the top-ranked parse hypothesis changes
between ticks. Reading-time cost = flip_weight * log(old_top / new_top), with
flip_weight=2.0 from the Narayanan model.

Caucheteux, C., Gramfort, A., and King, J.-R. (2023). "Evidence of a
predictive coding hierarchy in the human brain listening to speech."
Nature Human Behaviour, 7(3), 430-441. DOI: 10.1038/s41562-022-01506-8

Narayanan, S. and Jurafsky, D. (2004). "A Bayesian model predicts human
parse preference and reading time in sentence processing." Advances in Neural
Information Processing Systems 16. {DOI: To be added later.}

### RM403: Timmy

The integrated system. Binds all populations into one running environment with
the committed tick order:

1. LemmaStratum.tick(c_lex, g_t, x_t, tau_proj, r_reentry, omega, teach_label)
2. Read c_cas from lemma stratum output.
3. IamCore.forward(coords=c_cas) — c_cas goes ONLY here.
4. Cache new r_reentry (sliced to encoding_dim=64 from pcc_dim=128) and omega.
5. CascadeComposer.tick(a_l) using stratum activation.
6. Return TimmyStep.

The 160 ms re-entry delay is handled inside LemmaStratum.tick via its internal
deque. Timmy does not manage this delay directly.

The omega None contract: IamCore suppresses omega on theta-blocked ticks.
Timmy substitutes the last-known omega so the three-factor gate in the lemma
stratum has stable neuromodulatory input across theta windows.

The cold_start_naming_dialogue method runs a structured teach-sleep-recall
cycle and returns a transcript string. During teaching, ablate_three_factor is
temporarily set True (dopamine-burst-only gate) because the explicit teacher
IS the coincidence trigger in a structured naming session — requiring local
membrane depolarization from a cold untrained network would permanently block
boot-time acquisition.

### RM404: CurriculumRuntime

Staged developmental schedule. Eight stages (0-7) proceeding from phonemic
discrimination through generalized composition. Data loaded from
curriculum_data/*.json at runtime. Failure handling: if a stage does not reach
its exit metric after max_stage_attempts=3 retries (1x, 2x, 4x teaching
repetitions), the curriculum pauses and emits a diagnostic report for
Amellia's disposition. The curriculum does not silently retry forever.

Stage exit metrics:

| Stage | Name | Exit criterion |
|---|---|---|
| 0 | Phonemic discrimination | Chung parallelism >= 0.70 |
| 1 | Segmentation | >= 80% boundary detection |
| 2 | Word-object grounding | >= 200 CONFIRMED lemmas AND >= 90% retrieval |
| 3 | Frame-based generalization | >= 80% novel sentence correctness |
| 4 | Morphology | >= 80% inflection + stem extraction |
| 5 | Reading bootstrap | >= 80% direct, >= 70% indirect |
| 6 | Syntactic composition | >= 75% parse accuracy |
| 7 | Generalized composition | Phase 9 acceptance thresholds |

## Cross-cutting commitments

These were set in the Genesis letter and cannot be changed without surfacing
to Amellia.

1. Tied weights everywhere bidirectional. One nn.Parameter, forward uses
   direct multiply, reverse uses .t(). Two Linear layers with the same shape
   are not tied.

2. SSM-LIF substrate throughout. Every neuron in every population (L, P,
   B44, B45, O, X, the segment decoder, all four I-am core populations) is
   SSMLIFSubstrate. Any deviation stops the build.

3. No symmetric backpropagation across the organ. Updates are local:
   R-STDP under three-factor gate for plasticity, surrogate gradient within
   a single training pass for the decoder. No end-to-end backprop across
   PART files.

4. Three-factor gate applies wherever plasticity fires. Cholinergic pause +
   dopamine burst + local membrane depolarization. All three, per R2 tick,
   per row.

5. Sleep consolidation is offline. R4 does not run concurrently with R1, R2,
   R3. The curriculum schedules sleep between teaching batches.

6. tau_proj guard at every acquisition site. tau_proj=1 content may activate
   and spread but cannot anchor new acquisitions in L, write new codes in P,
   or commit new orthographic mappings in O.

7. Scaffold lock at every R3 step. SCAFFOLD-status rows: zero velocity and
   acceleration at every spring-dynamics tick. Pairwise distances among the
   ten scaffold anchors are maintained exactly.

8. Soul serialization mandatory. Every population, projection, buffer, and
   per-lemma record survives get_state() / load_state() roundtrip exactly
   under torch.equal.

9. 100% spiking is non-negotiable. The de novo aspect is the most important
   architectural commitment. Confirmed by audit at every PART completion.
